# Job Cards Component (React + Vite)

A clean and responsive Job Listing Cards component built with React and Vite. It displays dynamic job cards with company details, role, salary, tags, and action buttons.

## 🚀 Features

- Dynamic card data rendering using React props
- Clean and responsive layout
- Modern icons using `lucide-react`
- Fast development setup powered by Vite

## 🛠️ Tech Stack

- **React**
- **Vite**
- **CSS3**
- **Lucide React**

## 💻 Getting Started

1. **Clone the repo:**
   ```bash
   git clone <your-repo-url>
   cd card-component
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run local server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
